# Employee Data Cleaning & Analysis using Pandas

A beginner-level data cleaning and analysis project using Python and Pandas.

## Project Overview

This project focuses on cleaning and analyzing an employee dataset using Pandas.

## Objectives

- Handle missing values
- Clean inconsistent text data
- Check data types
- Identify duplicate data
- Sort and filter data
- Perform basic salary and experience analysis
- Extract useful insights

## Dataset

The dataset contains employee information including:

- Employee Name
- Salary
- Department
- Experience
- City

## Tools & Technologies

- Python
- Pandas
- Google Colab

## Data Cleaning

The dataset was cleaned by:

- Handling missing values
- Cleaning extra spaces
- Standardizing text capitalization
- Checking data types
- Checking duplicate data

## Data Analysis

The project includes:

- Salary analysis
- Experience analysis
- Department analysis
- City-wise employee counts
- Sorting and filtering
- Finding highest and lowest values
- Calculating averages

## Key Insights

- Total employees: 5
- Average salary: ₹38,750
- Highest salary: ₹60,000
- Average experience: 3 years
- IT is the largest department with 4 employees
- Jaipur and Delhi have 2 employees each
